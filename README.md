# Journeyman
## Overview

This project is a vertical slice of a Tunic-style action-adventure game, developed as part of the Journeyman group project. The goal was to create a playable prototype that demonstrates core gameplay mechanics including exploration, combat, and environmental interaction.

## Features

* Player Controls: Smooth movement and responsive combat mechanics.

* Enemy AI: Basic pathfinding and attack behaviors.

* Interactive Environment: Pickups, hazards, and environmental interactions.

* Modular Design: Systems designed for easy expansion and iterative development.

## My Role

As Lead Programmer, I focused on team coordination and project integrity rather than direct implementation:

* Delegated tasks to programming team members and tracked progress.

* Reviewed and ensured the quality of Blueprints and gameplay systems.

* Managed GitHub repositories and handled code merges to maintain stability.

* Facilitated communication between programmers and other team disciplines (design, art, etc.).

## Project Goals

* Deliver a polished, playable vertical slice.

* Demonstrate effective team collaboration and system coordination.

* Provide a foundation for future expansion into a full game.
